Protected scope
---------------

Task N may change only flight-geometry, flight-math, their frozen manifests,
and the minimum cargo-flight-lint precision rule/tests. It must not rewrite
flight-path's existing 208 `allow(f64)` annotations or any downstream crate.
That changed-file constraint is audited from the Task N diff because later
approved migration tasks intentionally change downstream crates.
