# GUI

Complete source port of Flight a62784923f3be814463286c9fb28edfe6ab15789: 20 production files (18 implementation modules and two export barrels), all 18 source suites, and all 115 original case declarations. The native suite also checks construction identity, retained references, callback reentry, cleanup order and timer cancellation. The Rust convenience layer delegates every controller operation and provides node helper extension methods; inline per-method tests compare it with the canonical free functions. Generic construction uses `from_runtime`, and generic disposal keeps its full name to avoid collisions with concrete controller aliases. The source public export surface is retained; the contract lane additionally exposes runtime and construction helpers.

Controllers adopt caller-owned visuals and derive source subscriptions and private state at construction. Source options, required references and defaults are retained. Construction initializers preserve the controller Entity's private runtime and UID. Shared runtime, signal, item, entry and result handles retain identity; copied source arrays copy their container and retain the same elements. Dialog queue output takes a required first output buffer, clears it and refills it in FIFO order.

Callbacks and transitions run without GUI or node guards. Disposal disconnects stored SlotIds in reverse order, restores prior hit-test/hit-area state, and runs clear once. The cleanup list remains live during its callbacks. Composed controllers use the actual child runtime after releasing the child's outer guard. TextInput connects the original canonical signals through their retained groups. GuiDialog uses the accepted Interaction shared-manager focus setter for activation and restoration, including nested close callbacks.

Native dependencies follow D5. Slider, ScrollBar, ScrollView, SplitPane and Window take the caller's shared `NodeRevisionState` for actual bounds. ScrollBar and Tooltip take the canonical `HostTimerCapability`; scheduling uses its queued callbacks and cancellation handles. Tests supply a deterministic scheduler through that actual capability. Geometry, Interaction, Text and TextInput remain owned by their existing crates.

The two source packages-external tree-shaking cases have native implementation graph counterparts: starting at Button or GuiDialog, traverse actual crate-qualified implementation dependencies and keep external packages external. They check the same excluded controller/application/tween dependencies. These are graph checks, not linked artifact or bundle size measurements.

Run `cargo test -p flight-gui --offline --locked`, scoped strict lint, and pinned conformance with the workspace lint tool. The flat test harness is generated by `cargo-flight-lint fix --crate flight-gui`.

## Precision

GUI arithmetic and node fields use canonical f32. `number_value` and `read_visual` losslessly project existing canonical f32 properties into the shared `NodeInteractiveStateTransitionValue::Number(f64)` protocol; `write_visual` writes that existing protocol value back to the canonical f32 field. Host timer calls losslessly promote the source-configured canonical delay into the existing host millisecond protocol. Keyboard conversion writes the source's literal zero into the existing input timestamp protocol. These conversions introduce no new public numeric types.

`snap_gui_grid` is the bounded D1 exact integer rounding adapter: lossless promotion of canonical inputs preserves the source Number subtraction/division, Math.round grid index (ties toward positive infinity), and final multiply/add before the canonical f32 write. Early f32 rounding incorrectly snaps 0.49999997 with minimum 0/step 1 to 1, and -2^-25 with minimum -1/step 2 to 1; exact regression expectations are 0 and -1. Other GUI arithmetic remains canonical f32. Original floating expectations use the approved D1 bounds where f32 representation requires them; identities, bytes, booleans, counts and rounded grid outputs are exact.
