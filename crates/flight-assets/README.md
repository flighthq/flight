# flight-assets

An open, reference-counted asset catalog over the canonical resource loader, ported from the delivered TypeScript snapshot `a62784923f3be814463286c9fb28edfe6ab15789`. Applications register arbitrary string asset types and adapters; the library installs no built-in resource adapters or concrete image/audio/video dependencies.

Each AssetLibrary Entity owns a separate `library_runtime` record, preserving the source library's `runtime` independently of the private Entity binding/uid slot. Descriptors are copied, group tags are unique and ordered, and snapshots are detached. Manifest registration keeps the final duplicate descriptor and preflights acquired replacements before making any mutation.

Acquisition starts its synchronous adapter prefix immediately and returns a canonical SharedFuture. Concurrent same-id acquires share the same promise and load while incrementing live references. The approved native bridge retains actual registered generic adapter references, callback fields, descriptors, opaque values, null, rejections and typed promise projections without JSON conversion. `AssetEntry.value: Option<Unknown>` distinguishes source undefined from loaded null; `get_asset::<Unknown>` consequently distinguishes nonresident None from resident Some(None). Failed entries can be retried; released pending entries free their eventual orphan once, and entry identity protects a later acquisition from stale completion.

A retained ResourceLoaderContext supplies the actual canonical spawner, queued timers and clock. The host drives asynchronous continuations; this crate starts no executor, transport or native timer. The driver retains each operation's original runtime until settlement, while weak continuation references avoid a self-owning promise cycle. Releasing or disposing a library never cancels an already-started adapter future.

Group preload uses the actual canonical loader's default bounded concurrency. Resident members take extra holds; scheduled members report settled/total counts. Settlement handlers are installed before start, all results are awaited, successful members remain held on failure, and the first failed member in group order supplies the rejection. Release and disposal preserve live ordered iteration and callback reentry without holding library or record locks across callbacks.

Guards retain caller-owned canonical LogState and sample the library's original host clock on each operation. Their enabled query compares the actual installed callback identity. Logging keeps the exact source warning keys, fields, channel and guidance, while core acquisition keeps its terse rejection. Initialization, acquire-hook installation, and the two exact closed-status string tables remain contract-only. Nineteen inline comparisons cover every owned native constructor, initializer and method.

Principal137e9de4 rules that a same-id acquire during the adapter's synchronous load prefix, or a later acquire after that prefix throws, cannot return the source's actual null under its declared Promise<T> contract. Native code throws a clear programmer Error for this half-initialized branch. Those null-promise runtime cases are explicitly nonrepresentable; they are not replaced with fabricated pending or rejected promises. All schema-valid source assertions are ported.

Nine item-scoped lint markers cover two D9 status-table extras, three D5 constructor/logger parameter seams, and four approved native generic signatures. No f64 is introduced here: clock precision remains in the canonical host capability. There are no conformance skips, numeric-array waivers, hidden-state exceptions, or new baseline entries. Rust's escaped r#type parameter uses the canonical linter's raw-identifier normalization without a waiver.
